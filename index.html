AI & Speech Recognition

Readify: Architectural Deep Dive

Readify was developed to address reading fluency, cadence, and comprehension hurdles through real-time algorithmic audio analysis.

1. Real-Time Speech Processing Pipeline

The client interface captures microphone input streams through the Web Audio API and transmits digitized chunks to the Python speech recognition backend. The engine performs noise cancellation, phoneme separation, and compares vocalized words against the reference text corpus.

2. Natural Language Processing & Fluency Scoring

The NLP pipeline assesses:

  • Words Per Minute (WPM): Dynamic calculation filtering hesitation pauses.
  • Pronunciation Clarity: Phonetic distance metric scoring syllable articulation.
  • Comprehension Confidence: Adaptive assessment tracking reading rhythm and pauses.

3. Interactive React Dashboard

Built with React.js, featuring real-time visual cadence charts, historical progress metrics, and algorithmic recommendations suggesting graded texts tailored to the reader's fluency level.
